# JARVIS Assistant

Projeto experimental de assistente pessoal com foco em IA, automação de tarefas e integração entre computador e dispositivos móveis.

## Status
**Experimental / protótipo.**

## Objetivo
Explorar uma arquitetura de assistente capaz de interpretar comandos e acionar automações locais de maneira controlada.

## Componentes planejados
```
desktop/
android/
server/
docs/
README.md
.gitignore
```

## Áreas exploradas
- Assistente para desktop
- Aplicativo Android
- Interpretação de comandos
- Integração entre cliente e serviço
- Automação local

## Segurança
Credenciais, tokens, chaves de API e segredos nunca devem ser incluídos no repositório. A execução de ações locais deve utilizar permissões mínimas e comandos explicitamente autorizados.
